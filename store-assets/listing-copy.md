## Detailed description

Schedule a prompt now, walk away, and it sends itself later — even in a background tab. AI Message Sender works on ChatGPT, Claude, and Gemini out of the box, and on any other webpage with a text input and a send button, so it isn't locked to one AI provider.

WHAT IT DOES
• Delay send — fire a prompt in 5 minutes, 15 minutes, an hour, or any custom time.
• Schedule for later — pick an exact date and time.
• Reset-aware sending — detects "resets in 2 hours" style usage banners and times your next prompt to land right when your limit refreshes.
• Chain sends — automatically send your next prompt ~500ms after the AI's current response finishes, so multi-step conversations run themselves.
• Recurring rules — daily or weekly prompts on a schedule, without re-queuing every time.
• Multi-tab, multi-queue — schedule several prompts across several tabs at once.
• Dry-run testing — verify a scheduled prompt will actually land in the right input and send button before you trust it with a real send.
• Works on any site — a point-and-click picker teaches the extension any input field and send button, on any webpage, not just the built-in platforms.
• Full history — every send and attempt logged for 30 days, with pass/fail status.

HOW IT WORKS
Open the extension on the tab you want to schedule, pick a time mode, teach it the input box and send button (skip this on ChatGPT/Claude/Gemini — it already knows them), write your prompt, and queue it. The tab can sit in the background; it'll be brought to the front automatically when the moment comes.

PRIVACY
Everything is stored locally in your browser. There's no backend server, no analytics, and no telemetry — the extension code makes zero network requests of its own. Cross-device sync (optional) uses your own Google account via chrome.storage.sync, never a server we operate. Full privacy policy linked in this listing.

LIMITATIONS (so you know what to expect)
Scheduled sends depend on your browser being open — the source tab must stay open, and Chrome itself needs to be running (sleep is fine, a full quit is not). This is a browser-based scheduler, not a cloud service.

Built and maintained by one person. Bug reports and feature requests are genuinely welcome — GitHub issues link is in the listing.
