Quick start

Five quick steps. Your first scheduled prompt is two minutes away.

  1. 1

    Teach the input box

    Open a Claude/ChatGPT/Gemini tab. Click the AI Auto-Sender icon, then "Teach input" and click the prompt box.

  2. 2

    Teach the send button

    Same flow, but pick the send arrow.

  3. 3

    Queue a message

    Type a prompt, pick a delay, click Queue.

  4. 4

    Try dry run

    Click "Dry run" on your queued item. You'll get a dialog describing each step.

  5. 5

    You're set up

    The extension will fire at the scheduled time. You can close this tab.

How it works

The short version, always here even after you've finished the tour above.

  1. 1

    Teach the input and send button

    Open any page with a text box and a send button — an AI chat site or any other webpage. Click the extension icon, "Teach input," then click the box. Same for "Teach send."

  2. 2

    Write a prompt and pick when

    Type your message, then choose Delay (a relative offset), At time (an exact date/time), Chain (right after the current response finishes), or Reset (when this page's rate limit clears).

  3. 3

    Queue it

    Click "Queue prompt." The item shows up in the Queue list — you can dry-run it (see each step it would take, without actually sending) or cancel it any time before it fires.

  4. 4

    Keep the tab open

    At the scheduled moment, the extension focuses the tab, types your message in, and clicks send — as long as that tab and Chrome are still open. See Limitations below for the exact constraints.

  5. 5

    Check History

    Every send — successful or failed — is logged for 30 days with the full prompt text, so you can confirm it went out or see why it didn't.

Time modes in the popup

Four ways to schedule a message. Switch between them at any time.

Delay
Send after a relative offset — +5m, +15m, +1h, or tomorrow 9am.
At time
Send at an exact date and time. Type the 5 fields, then press Confirm.
Chain
Sends the prompt ~500ms after the current AI response ends on the same tab. Useful for follow-ups.
Reset
Scans the page for a rate-limit notice — "resets in 2 hours" or "until 8:40 PM" style — and schedules the message for that moment.

Limitations

Scheduled sends depend on your browser, not a server — a few real constraints follow from that.

  • The tab you scheduled a message in must stay open. Closing it cancels that send — you'll see it marked "tab lost" in History.
  • Chrome itself must be running. If you fully quit Chrome, queued sends fire late once you reopen it, not retroactively at the original time.
  • Your device just needs to be awake — a locked screen is fine, sleep or hibernate is not.
  • Works on any webpage with a text input and a send button — not limited to Claude, ChatGPT, or Gemini.
