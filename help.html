Help & support.

Everything the extension does, what it can't do, and how to reach me if something's wrong.

Features

Works on any webpage with a text input and a send button — not limited to Claude, ChatGPT, or Gemini.

  • Teach picker — click to map the input field and send button on any page, once per site.
  • Delay — send after a relative offset (+5m, +15m, +1h, tomorrow 9am).
  • At time — send at an exact date and time.
  • Chain — send ~500ms after the current AI response finishes on the same tab.
  • Reset — scan the page for a rate-limit notice and send the moment it clears.
  • Recurring rules — repeat a prompt on a schedule instead of queuing it once.
  • Dry run — preview exactly what a queued item would do, without actually sending it.
  • History — every send, successful or failed, logged with full prompt text for 30 days.
  • Cross-device sync — taught selectors and settings sync via your Google account, never through a server we run.

Limitations

Scheduled sends depend on your browser, not a server — a few real constraints follow from that.

  • The tab you scheduled a message in must stay open. Closing it cancels that send — you'll see it marked "tab lost" in History.
  • Chrome itself must be running. If you fully quit Chrome, queued sends fire late once you reopen it, not retroactively at the original time.
  • Your device just needs to be awake — a locked screen is fine, sleep or hibernate is not.
  • The picker won't select overlays, dev/UI portals, or hidden elements — pick the real input or button, not a wrapping container.

FAQ

Common questions, answered directly.

Why didn't my scheduled message send?

One of three things: the tab was closed before the scheduled time, Chrome was fully quit (not just backgrounded), or your device was asleep or hibernating. Check History — failed items are marked with the reason.

Does this only work on Claude, ChatGPT, and Gemini?

No. It works on any webpage with a text input and a send button. Those three platforms have built-in defaults, but you can Teach the input and send elements on any other site the same way.

The picker won't let me select the element I clicked.

The picker rejects overlays, modals, hidden elements, and known dev/UI portals — the floating label tells you why when it happens. Try clicking directly on the input box or button itself, not a container wrapping it.

"No reset time detected on this page" — what does that mean?

Reset mode scans the page's visible text for a rate-limit phrase like "resets in 2 hours" or "until 8:40 PM." If that banner hasn't loaded yet, or the site's exact wording isn't recognized, nothing is found. Try again once the banner is visible, or use Delay/At time instead.

Chain mode isn't firing after the response finishes.

Chain watches for the platform's "stop generating" control to disappear. If the tab is closed, backgrounded incorrectly, or a site redesign changed its DOM, detection can miss. Report it (below) with the site's URL so the adapter can be patched.

Is my data sent anywhere?

No — the extension code makes no network requests. Everything lives in chrome.storage.local, optionally synced via chrome.storage.sync (that's your Google account, not a server of ours). Full detail on the Privacy page.

How do I wipe everything and start over?

Options page → Maintenance section → Wipe local data / Clear synced selectors. Uninstalling the extension also removes all stored data.
