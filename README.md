# AI Message Sender

Schedule text prompts to Claude, ChatGPT, and Gemini — with multi-queue, multi-tab, dry-run, recurring schedules, and selector sync.

## Develop

```bash
npm install
npm run lint && npm test && npm run build
```

## Package for the store

```bash
npm run zip
# → dist/ai-auto-sender-v5.0.0.zip
```

See `docs/STORE_LISTING.md` for the Chrome Web Store copy and `docs/TEST_MATRIX.md` for the pre-release manual checks.
